# How to contribute

First, thank you for even considering this project!

I created it to scratch my own itch, for a fully featured package that integrates with the Linux network stack, using the Netlink and Generic Netlink protocols and no third-party dependencies or shell commands.


## Contributing Issues

The best way to contribute is through issues.

I only have access to a finite set of platforms and scenarios to test against, everything else is largely guesswork.

If a use case is not well supported, or the API doesn't implement said use case correctly, opening an issue with as much detail as possible helps rectify that.

In particular, issues that contain a detailed description of the use case, example code, and dumps of the bytes sent to and from the Netlink socket to build tests with, are **very** welcome.


## Contributing Code

In the current age of AI and LLM generated code and pull requests, this project takes a [similar approach to SQLite](https://sqlite.org/copyright.html): open source, not open contribution.

I would prefer open contribution, hence the permissive BSD 3-Clause license, however at the time of writing this does not feel feasible. I am open to this changing as this ecosystem develops.

Anyone showing real interest in helping develop and maintain the source, will be added as a contributor, with the ability to raise and review pull requests.

Everything contained within this project is under the BSD 3-Clause license, and contributors agree they are free to make submissions and their submissions are under said license.
